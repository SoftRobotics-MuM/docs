# 3D Printing

## PrusaSlicer Setup

### Printer

Original Prusa MK4 Input Shaper

### Nozzle

0.4 mm nozzle

### Filament

Generic PLA or Prusament PLA profile

### Print Settings

Especially for casting molds, adjusting the layer height can help reduce ridges in the silicone body. Use variable layer height to refine critical areas where necessary.

## File Naming

Before uploading a print file to the printer, prefix the **file name with your name**.
